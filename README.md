- **APIs**: RESTful APIs for AI predictions and market data

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn
- VS Code (recommended)

### Installation

1. **Clone the repository**
\`\`\`bash
git clone https://github.com/arunav/stockera.git
cd stockera
\`\`\`

2. **Install dependencies**
\`\`\`bash
npm install
\`\`\`

3. **Set up shadcn/ui**
\`\`\`bash
npx shadcn@latest init
npx shadcn@latest add button card input label badge tabs alert scroll-area separator select checkbox dropdown-menu toast tooltip
\`\`\`

4. **Start development server**
\`\`\`bash
npm run dev
\`\`\`

5. **Open in browser**
\`\`\`
http://localhost:3000
\`\`\`
